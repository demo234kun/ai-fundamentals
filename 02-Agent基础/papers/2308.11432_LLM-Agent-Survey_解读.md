# 《A Survey on Large Language Model based Autonomous Agents》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Lei Wang 等，人大 + 清华等 |
| 发表 | arXiv:2308.11432（2023.8，持续更新版） |
| 一句话总结 | 最早系统化 LLM Agent 的综述，提出 **Profile / Memory / Planning / Action** 四组件框架 + 统一 evaluation 视角，是入门该领域的地图 |

## 1. 为什么先读这篇

- 2023 年 agent 工作爆发但概念混乱（AutoGPT、BabyAGI、ReAct、Toolformer……），本文把碎片整理成框架。

## 2. 核心框架（本文精华）

- **Agent Profile**：agent 扮演什么角色（人工设定/LLM 生成/数据集对齐）。
- **Memory**：感觉记忆（上下文）、短期记忆（缓冲）、长期记忆（外部向量库）。
- **Planning**：无反馈规划（CoT/ToT）vs 有反馈规划（ReAct/Reflexion）。
- **Action**：工具使用（调用外部 API / 执行代码）、知识检索（RAG agent 化）、环境交互（embodied）。
- **Evaluation**：主观（人评）/客观（指标、benchmark）+ 游戏/推理/工具使用等场景分类。

## 3. 价值与局限

- 价值：给后续所有 agent 论文/框架提供词汇表；四个组件的拆解至今仍是教科书式的。
- 局限：2023 年视角，缺 multi-agent 协作、缺 RLVR 训练视角；中文社区另一篇 Xi et al. 2309.07864 视角互补。

## 4. 与本知识库的关联

模块 02 的目录骨架来源；速查某篇 agent 论文时先对照四组件定位它。

## 5. 阅读建议

- 不必通读：先读 §2（框架）和 §4（评估），其余当工具书查。
- 用法建议：每遇到新 agent 论文，用四组件各问一个问题——"它的记忆放哪？规划有没有反馈？动作空间是什么？"
