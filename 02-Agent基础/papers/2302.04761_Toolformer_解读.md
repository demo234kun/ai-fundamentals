# 《Toolformer: Language Models Can Teach Themselves to Use Tools》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Timo Schick 等，Meta AI |
| 发表 | arXiv:2302.04761（NeurIPS 2023） |
| 一句话总结 | 让模型自监督地学会何时调 API：自动给语料插入 API 调用、真执行、按"loss 是否下降"过滤，再微调——无需人工标注的工具学习 |

## 1. 研究背景与问题

- 教会 LLM 用计算器/日历/搜索引擎，过去靠人工标注"何时调工具"的数据。
- 问题：**能否自动构造工具调用训练数据？**

## 2. 核心方法（自监督数据工厂）

1. 用 few-shot 提示让 LM 在语料中"提议"API 调用位置（带占位符）。
2. 真正执行调用，把真实结果填回。
3. **过滤准则**：比较"插入调用后"与"原句"的 LM loss——loss 下降才保留（说明这个调用真的有帮助）。
4. 用过滤后的 2 万样本微调 6.7B GPT-J。

## 3. 关键实验与结果

- 在乘法、日期、问答等任务上大幅超越 10 倍大的 OPT/GPT-3 zero-shot 基线。
- 模型自己学会"只在需要时调用"——简单加法自己算，大数才调计算器。

## 4. 局限性与争议

- 逐 token 插入效率低；一次只调一个工具。
- 对"工具组合"与"多跳"支持弱。

## 5. 与本知识库的关联

模块 02 第 3 节"工具学习"的起点；现代 function calling 微调数据的鼻祖。

## 6. 阅读建议

- 精读 §2（采样+过滤流程），这是全篇最有复用价值的部分。
- 思考：这套 loss-based 过滤思想可迁移到任何"自动构造 SFT 数据"场景。
