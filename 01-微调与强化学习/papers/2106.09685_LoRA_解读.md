# 《LoRA: Low-Rank Adaptation of Large Language Models》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Edward Hu 等，Microsoft |
| 发表 | arXiv:2106.09685（ICLR 2022） |
| 一句话总结 | 冻结预训练权重，只训练低秩分解的增量矩阵，以不到 1% 的可训练参数追平全参微调 |

## 1. 研究背景与问题

- GPT-3 175B 全参微调一次要存 175B×(4+8) 字节优化器状态，单卡不可能；每个下游任务存一份全量副本，部署成本高。
- 已有方案（Adapter 在层间插小模块、Prompt Tuning 只调软提示）要么推理有额外延迟，要么效果不及微调。
- 问题：**能否既不增加推理延迟，又大幅减少可训练参数？**

## 2. 核心方法

- 权重更新矩阵 ΔW 用低秩分解表示：`W = W₀ + ΔW = W₀ + BA`，A ∈ R^{r×k}，B ∈ R^{d×r}，r ≪ min(d,k)（常用 16/64）。
- **初始化**：A ~ 高斯，B = 0 → 训练起点等价于原模型，训练稳定。
- **缩放**：前向实际为 `h = W₀x + (α/r)·BAx`，α/r 保证不同 r 下更新量级一致。
- **无推理开销**：推理时把 BA 合并进 W₀，或保留 adapter 按需切换。
- 关键实验结论：在 RoBERTa/DeBERTa/GPT-2/GPT-3 上，r=16 即追平或超过全参微调；r=4 时 ΔW 已能学到 "intrinsic rank" 很低的有效更新。

## 3. 关键实验与结果

- GPT-3 175B：可训练参数从 175B 降到 37.7M（0.02%），效果与微调持平。
- ΔW 与 W 相关性低、与任务相关性高——低秩增量确实捕捉到了任务特定方向。

## 4. 局限性与争议

- r 需要调参；对"需要大幅改变模型行为"的任务（如完全不同的领域）低秩可能不够。
- 后续 DoRA/PiSSA 指出 A、B 同学习率不是最优。
