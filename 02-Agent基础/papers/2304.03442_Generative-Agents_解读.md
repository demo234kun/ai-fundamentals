# 《Generative Agents: Interactive Simulacra of Human Behavior》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Joon Sung Park 等，Stanford + Google |
| 发表 | arXiv:2304.03442（UIST 2023，最佳论文） |
| 一句话总结 | 25 个"生成式智能体"在沙盒小镇里生活两天——记忆流 + 反思 + 计划的三层架构，让它们自发组织情人节派对，是 agent 记忆架构的最著名实验 |

## 1. 研究背景与问题

- 人类行为的可信模拟需要：长期记忆、在记忆之上做计划、动态反思修正。
- 问题：**纯 LLM 驱动的 agent 能否产生"涌现式社会行为"？**

## 2. 核心架构（记忆三部分）

1. **记忆流（Memory Stream）**：所有观察/思考/行动按时间序记录。
2. **检索（Retrieval）**：按 recency + relevance + importance 三因子加权取回记忆。
3. **反思（Reflection）**：记忆积累到阈值后，LLM 把原始记忆综合成高层洞见，递归生成反思树。
4. **规划（Planning）**：自上而下把"一天/一小时"计划展开成具体行动，与环境互动后动态调整。
- Agent 之间**自然语言交流**，对话内容进彼此记忆流。

## 3. 关键实验与结果

- 两天模拟后，agent 自发传播派对邀请、协作举办派对——涌现群体行为。
- 记忆检索三因子消融：缺一不可。

## 4. 局限性与争议

- 纯 prompt 架构，token 成本惊人；小镇是玩具环境。
- "可信人类行为"的评估依赖观察者判断，主观性强。
