# 《Tree of Thoughts: Deliberate Problem Solving with Large Language Models》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Shunyu Yao 等，Princeton + Google DeepMind |
| 发表 | arXiv:2305.10601（NeurIPS 2023） |
| 一句话总结 | 把 CoT 的"一条链"扩展成"一棵树"：每步采样多个候选、LM 自己打分、用 BFS/DFS 搜索——让 LLM 能做需要回溯的决策问题 |

## 1. 研究背景与问题

- CoT 是贪心的：一步走错无法回头。
- 问题：**能否让 LLM 像搜索算法一样"探索-评估-回溯"？**

## 2. 核心方法

- **思维分解**：把任务拆成几步，每步生成 k 个候选"思维"（CoT 分块）。
- **状态评估**：LM 对每个状态打 1-10 分（vote 或 value prompt）。
- **搜索算法**：BFS（按层扩展，保 top-k）或 DFS（深度优先，剪枝回溯）。
- 适用三类任务：创意写作、24 点、迷你填字。

## 3. 关键实验与结果

- Game of 24：CoT 只有 4% 成功率，ToT 达 74%。
- 代价：token 消耗是 CoT 的 10 倍以上。

## 4. 局限性与争议

- 需要任务可分解、可评估——开放任务难用。
- 成本高，实用中常被"自洽性采样（self-consistency）"这种更便宜的近似替代。
