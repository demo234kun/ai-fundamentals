# 《OpenHands: An Open Platform for AI Software Developers as Generalist Agents》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Xingyao Wang 等，UIUC + CMU 等多机构 |
| 发表 | arXiv:2407.16741（2024.7） |
| 一句话总结 | 开源的"Devin 竞品"平台：沙箱运行时 + 多 agent 架构（CodeAct）+ 完整评测闭环——研究 harness 架构的公开标本 |

## 1. 研究背景与问题

- 2024 年初 Devin 引爆"AI 软件工程师"，但全部闭源。
- 问题：**开源社区如何复现并超越其 harness 架构？**

## 2. 核心架构

1. **运行时（Runtime）**：每个 agent 会话跑在独立 Docker 沙箱里（文件系统 + bash + 浏览器 + Jupyter），通过事件流（event stream）与 agent 通信——沙箱与 agent 循环解耦。
2. **Agent 层**：可插拔（CodeActAgent / BrowsingAgent 等），动作以**代码**表达（CodeAct），观察结果回流。
3. **多智能体**：分派器（delegator）把子任务交给专门 agent。
4. **评估闭环**：内置 SWE-bench 等 benchmark 的一键评估。

## 3. 关键实验与结果

- CodeAct 代理在 SWE-bench 上超过此前的开源方案；后续迭代长期占据开源榜首。

## 4. 局限性与争议

- 系统复杂度高（事件流抽象多层），新手上手曲线陡；沙箱资源消耗大。

## 5. 与本知识库的关联

模块 05 五大组件的"完整实现参照物"：上下文组装、工具运行时、agent 循环、状态记忆、交付安全都能在它的代码里找到对应模块。
