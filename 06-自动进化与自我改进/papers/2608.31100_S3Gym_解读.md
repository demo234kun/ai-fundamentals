## 1. 研究背景与问题

- 自进化承诺"没有老师也能进步"，但链条有三环：Self-Testing（探出行为）、Self-Judging（判断好坏）、Self-Improvement（固化经验）。
- 问题：**经验以什么形式进入下一次决策才有效？自评可信吗？**

## 2. 核心方法

- **七游戏环境**：Chess、Minesweeper、Nullify、Tetris、Snake、PvZ、Trust Evolution——覆盖规则归纳、约束满足、空间推理、长程控制、资源分配、博弈。探索配置宽松、评测配置严格（测迁移）。
- **五阶段循环**：Explore → Judge → Consolidate → Update → Evaluate；verifier 奖励在探索期对 agent 隐藏，保证"自评"与"真实分"可对照。
- **三条经验通路**（对应模块 03 程序性记忆的光谱）：
  1. **History ICL**：原始轨迹直接进 prompt——信息全、占上下文；
  2. **Summary Memory**：压缩成"保留的策略/避免的错误"——省 token、靠抽象；
  3. **Parameter Training**：高分动作转 SFT 数据更新权重——最持久。

## 3. 关键实验与结果

- **无通吃通路**：Summary Memory 赢 Nullify/Tetris/Trust，History ICL 赢 Minesweeper/Snake/PvZ，Chess 3-3-1；换归一化指标（NABA vs 原始 AUC+）排行榜重排。
- **自评失效**：自评分与下一步真实增益 ρ = −0.010 / −0.018——自评不能当训练信号。
- **参数更新不稳定**：Qwen3-8B 20 个 checkpoint，Trust 上 18/19 高于基线（max +30），PvZ 从 23 跌到 6 后纹丝不动。

## 4. 局限性与争议

- 参数训练研究与上下文方法研究非同一批配对实验；PvZ 持续退化的原因未查明（作者明示 evidence boundary）。
- 文本游戏环境与真实工作流仍有差距。

## 6. 阅读建议

- 读 §3（协议）与三种通路的定义；重点看"自评 vs 真实收益"的散点图——它应该出现在每个做自进化系统的评审 checklist 里。
- 实践：给你的 agent 加"经验通路 A/B"开关，永远留一个 held-out 环境做裁判。
