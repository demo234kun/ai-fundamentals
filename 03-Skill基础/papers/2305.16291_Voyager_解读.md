# 《Voyager: An Open-Ended Embodied Agent with Large Language Models》解读

| 一句话总结 | Minecraft 终身学习 agent：自动课程提目标 → 代码当技能 → 技能库存量检索 → 反馈迭代纠错——模块 03 的奠基论文 |

## 1. 研究背景与问题

- 现有 agent 只能在固定任务上训练，不能持续积累能力。
- 问题：**如何构建能无限自我改进、技能可复用的开放世界 agent？**

## 2. 核心方法（三模块循环）

1. **自动课程（Automatic Curriculum）**：GPT-4 根据"当前状态 + 已有技能 + 探索目标"提出难度递增的任务。
2. **技能库（Skill Library）**：每个技能是一段**可执行代码函数**（附描述 embedding 存入向量库）；新任务先检索相关技能组合/修改，而非从零写——**程序性记忆的复利效应**。
3. **迭代式提示（Iterative Prompting）**：代码失败 → 错误回灌 → GPT-4 重写 → 成功才入库。

## 3. 关键实验与结果

- 零样本通关 Minecraft 主要科技线；技能可跨地图/跨会话复用。三模块消融缺一不可。

## 4. 局限性与争议

- 依赖 GPT-4 代码能力；技能检索是浅层 embedding 匹配；反馈循环慢、成本高。

## 5. 与本知识库的关联（Skill 视角）

模块 03 第 3 节"从经验中自动沉淀"的全部内容来源：**自动课程解决"学什么"、技能库解决"存什么"、迭代纠错解决"怎么保真"**——之后所有 skill 自动生成工作都是这三步的变体。

## 6. 阅读建议

- 精读 §3 与技能检索的案例（§4.2）。读完问自己：我的 agent 做完任务后，"技能"以什么形式留下来？
