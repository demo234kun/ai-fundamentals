| 项目 | 内容 |
|---|---|
| 作者/机构 | Guanzhi Wang 等，NVIDIA + Caltech + Stanford + UT Austin |
| 发表 | arXiv:2305.16291（TMLR 2024） |
| 一句话总结 | Minecraft 里的"终身学习"agent：自动课程提目标 → 代码当技能 → 技能库存量检索 → 环境反馈迭代纠错——玩越久越强，是 Skill 自动沉淀范式的源头 |

## 1. 研究背景与问题

- 现有 Minecraft agent 只会在固定任务上训练，不能持续积累能力。
- 问题：**如何构建能无限自我改进、技能可复用的开放世界 agent？**

## 2. 核心方法（三模块循环）

1. **自动课程（Automatic Curriculum）**：GPT-4 根据"当前状态 + 已有技能 + 下一步探索目标"提出难度递增的任务。
2. **技能库（Skill Library）**：每个技能是一段 **可执行代码函数**（JS），附描述 embedding 存入向量库；新任务先检索相关技能组合/修改，而非从零写。
3. **迭代式提示（Iterative Prompting）**：代码执行失败 → 把错误信息回灌给 GPT-4 重写 → 直到成功才入库；执行环境反馈（物品栏、血量）进入下一轮上下文。

## 3. 关键实验与结果

- 零样本通关 Minecraft 主要科技线（钻石级别），技能可跨地图/跨会话复用。
- 消融证明三者缺一不可（课程→探索广度；技能库→组合泛化；迭代→成功率）。

## 4. 局限性与争议

- 依赖 GPT-4 的代码能力；技能库检索是浅层 embedding 匹配。
- 环境反馈循环慢、token 成本高。
