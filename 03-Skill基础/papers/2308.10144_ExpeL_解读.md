# 《ExpeL: LLM Agents Are Experiential Learners》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Zhao 等，National University of Singapore |
| 发表 | arXiv:2308.10144（AAAI 2024） |
| 一句话总结 | 让 agent 从一批成功/失败轨迹中**自动提取自然语言"洞见"（insights）**并注入后续提示——与 Voyager 并列为经验沉淀的两大路线（轨迹蒸馏 vs 代码沉淀） |

## 1. 研究背景与问题

- Reflexion 只把单条失败经验带进下一轮，经验不累积、不跨任务。
- 问题：**能否从一批轨迹中归纳出可复用的"经验法则"？**

## 2. 核心方法

1. 收集 N 条成功 + N 条失败轨迹；
2. 让 LLM 对比两组轨迹，归纳出若干条**经验洞见**（如"先检查物体是否在背包再尝试使用"）；
3. 去重、按有效性排序，作为 prompt 前缀注入后续同类任务；
4. 新经验持续合并进经验池（动态演化）。

## 3. 关键实验与结果

- 在 AlfWorld、WebShop、Mind2Web 上，经验注入后成功率大幅提升，且经验可跨任务迁移。

## 4. 局限性与争议

- 洞见是自由文本，长度膨胀快；错误洞见会系统性误导（比单条错误更危险）。
- 无验证机制——与 Voyager 的"执行成功才入库"形成对照。

## 5. 与本知识库的关联（Skill 视角）

模块 03 中"三代形态"之三（机沉淀）的另一条腿：**Voyager 沉淀代码，ExpeL 沉淀文字经验**——后来 SKILL.md 式技能其实介于两者之间（结构化文字 + 可执行资源）。
