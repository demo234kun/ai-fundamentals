# 《Reflexion: Language Agents with Verbal Reinforcement Learning》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Noah Shinn 等，Northeastern + MIT |
| 发表 | arXiv:2303.11366（NeurIPS 2023） |
| 一句话总结 | 失败后不硬重试，而是把失败经验写成文字"反思"存入情景记忆，下一轮带着反思重来——用语言实现了强化学习的"试错改进" |

## 1. 研究背景与问题

- ReAct 等 agent 失败后只是重试，同样错误反复犯。
- 问题：**如何让 agent 从失败中学习，而不更新权重？**

## 2. 核心方法

1. **Actor**：ReAct 式生成动作（LLM）。
2. **Evaluator**：给轨迹打分（环境奖励或 LLM 自评）。
3. **Self-Reflection 模型**：失败后生成一段文字总结"哪里错了、下次怎么改"。
4. **Episodic Memory**：存反思摘要；下轮 prompt 注入最近几条反思。

等价视角：** verbal RL**——经验以自然语言形式在"情节"间传递，零梯度更新。

## 3. 关键实验与结果

- HumanEval 代码：Reflexion 把 GPT-4 pass@1 从 80% 提到 91%；ALFWorld 任务成功率 97%（vs ReAct 73%）。

## 4. 局限性与争议

- 反思质量依赖底层模型；错误反思会误导。
- 只记"最近一次"任务的经验，无跨任务泛化（ExpeL/Voyager 补这个）。

## 5. 与本知识库的关联

模块 02 Planning；模块 03 Skill 自动沉淀的技术基础之一。
