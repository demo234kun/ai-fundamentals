# 《DeepSeekMath: Pushing the Limits of Mathematical Reasoning》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Zhihong Shao 等，DeepSeek-AI |
| 发表 | arXiv:2402.03300（2024.2） |
| 一句话总结 | 提出 GRPO——用"组内相对排名"代替 Critic 的价值估计，把 RL 训练成本砍半，7B 数学模型逼平 GPT-4 |

## 1. 研究背景与问题

- PPO 训练 LLM 要同时在显存放 4 个模型，成本极高。
- 问题：**能否不用 Critic（价值网络） still 做稳定的 actor-critic 式 RL？**

## 2. 核心方法（GRPO）

1. 对同一 prompt q，从旧策略采样一组 G 个回答（G=64）。
2. 组内标准化当优势：`A_i = (R_i − mean) / std`——**组均值就是该 prompt 价值的蒙特卡洛估计**。
3. 目标函数沿用 PPO 的 clipped surrogate + KL 正则（相对参考模型）。

   `L = −E[ min(ρ_i A_i, clip(ρ_i, 1±ε) A_i) ] − β·D_KL(π_θ ‖ π_ref)`

- 省去 Critic：少一个与策略同等大小的模型和它的训练不稳定。
- 对 reasoning 任务可加过程奖励（每个推理步骤打分）——论文与 R1 路线的重要衔接点。

## 3. 关键实验与结果

- DeepSeekMath-RL 7B 在 GSM8K 88.2%、MATH 51.7%（当时开源 SOTA，接近 GPT-4 早期水平）。
- 证明"组相对"在 LLM 规模上稳定可用。

## 4. 局限性与争议

- 组内 std 很小（奖励全对/全错）时梯度信号弱——G 要足够大。
- 依赖可验证奖励（数学答案对错）；开放式任务仍需 RM。
