## 1. 研究背景与问题

- REALM 证明检索增强预训练可行，但只在 BERT 规模。
- 问题：**对 7B~25B 的生成式 LLM，预训练时持续给检索上下文，值不值？**

## 2. 核心方法

- 预训练语料的每个 chunk，把"前文最近块 + 外部检索的相似块"拼进上下文（与 RETRO 同期思路，但更简单：检索器冻结）。
- 关键评估：困惑度、下游 few-shot、**"等效参数"**——带检索的 7B 模型相当于多大无检索模型？

## 3. 关键实验与结果

- 7B 模型困惑度大幅下降；等效参数提升数倍（如 7B+检索 ≈ 25B 的部分能力）。
- 检索器冻结即可，不用联合训练——工程上便宜很多。

## 4. 局限性与争议

- 需要预训练级别的算力才能享受收益，普通团队用不上。
- 与 RAG 的推理期检索是互补而非替代关系。
