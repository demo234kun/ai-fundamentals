# 《A Survey on Large Language Model based Autonomous Agents》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Lei Wang 等，人大 + 清华等 |
| 发表 | arXiv:2308.11432（2023.8） |
| 一句话总结 | LLM Agent 领域最早的系统化综述：Profile / Memory / Planning / Action 四组件框架——Skill 是其中"能力获取（capability acquisition）"问题的解 |

## 1. 为什么 Skill 模块要读这篇

- 本文把 agent 能力来源分两类：**预训练权重** vs **上下文临时获取**；当时还没有"技能"这个中间层。
- 模块 03 的核心论点——"把程序性知识外置成可复用文件"——正是补上了四组件框架里缺失的"能力沉淀"环节。

## 2. 核心框架速览

- Profile（角色）、Memory（感觉/短期/长期）、Planning（无反馈 vs 有反馈）、Action（工具/RAG/环境交互）、Evaluation（主观/客观）。

## 3. 与本知识库的关联（Skill 视角）

用四组件拆解 skill 系统：**Skill 是 Procedural Memory 的载体、是 Action 的说明书、其索引常驻 Profile 层**——读这篇可以训练"组件化拆解任何 agent 系统"的能力。

## 4. 阅读建议

- 只读 §2 框架部分即可（约 30 分钟）；其余当工具书。配套读 Xi et al.（arXiv:2309.07864）对比两个框架。
