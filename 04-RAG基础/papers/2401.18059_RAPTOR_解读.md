# 《RAPTOR: Recursive Abstractive Processing for Tree-Organized Retrieval》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Parth Sarthi 等，Stanford |
| 发表 | arXiv:2401.18059（ICLR 2024） |
| 一句话总结 | 递归聚类 + 摘要生成"摘要树"：叶子是原文块，越往上越抽象，检索可跨层级进行——让 RAG 同时照顾细节问题与跨章节全局问题 |

## 1. 研究背景与问题

- 固定分块在"细节检索"上好，但"第 3 章和第 7 章综合起来说明了什么"这类跨章问题需要高层概括。
- 问题：**能否让索引自带多抽象层级？**

## 2. 核心方法

1. **递归嵌入与聚类**：对块向量做高斯混合模型软聚类；
2. **摘要**：对每个聚类用 LLM 生成摘要，摘要再作为"块"进入上一层递归；
3. **检索**：按 query 在树的任意层级取相关节点（通常"具体 query 取叶、抽象 query 取上层"）；
4. 与 GraphRAG 的区别：RAPTOR 是**自下而上的聚类摘要**（无显式图谱），GraphRAG 是**实体关系图 + 社区摘要**。

## 3. 关键实验与结果

- 多跳问答（NarrativeQA 等）上超越 Dense Passage 与 naive RAG 10%+。

## 4. 局限性与争议

- 摘要失真会逐层放大（上层摘要是"摘要的摘要"）；索引成本不低。
