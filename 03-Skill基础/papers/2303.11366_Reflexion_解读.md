# 《Reflexion: Language Agents with Verbal Reinforcement Learning》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Noah Shinn 等，Northeastern + MIT |
| 发表 | arXiv:2303.11366（NeurIPS 2023） |
| 一句话总结 | 失败后把经验写成文字反思存入情景记忆，下轮注入——"语言化自我改进"，是 skill 生成机制的底层积木 |

## 1. 研究背景与问题

- ReAct 式 agent 失败后硬重试，同样错误反复犯。
- 问题：**如何不更新权重就能从失败中学习？**

## 2. 核心方法

1. Actor 生成动作；Evaluator 给轨迹打分；
2. Self-Reflection 模型生成文字总结："哪里错了、下次怎么改"；
3. 反思存入 episodic memory，注入下轮 prompt。
等价于**用文字当梯度**的 verbal RL。

## 3. 关键实验与结果

- HumanEval：GPT-4 pass@1 80% → 91%；ALFWorld 73% → 97%。

## 4. 局限与争议

- 反思质量依赖模型；错误反思会误导；无跨任务累积。
