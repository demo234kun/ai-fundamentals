# 《ReAct: Synergizing Reasoning and Acting in Language Models》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Shunyu Yao 等，Google Brain + Princeton |
| 发表 | arXiv:2210.03629（ICLR 2023） |
| 一句话总结 | 把 CoT 推理轨迹与工具调用动作交织生成，互相促进——推理指导行动、行动反馈纠正推理，Agent 领域的奠基范式 |

## 1. 研究背景与问题

- 纯 CoT：会"想"不会"查"，事实错误无法自检。
- 纯行动（传统 RL agent）：不会解释、样本效率低、难调试。
- 问题：**能否让语言模型同时产生推理与行动，且两者协同？**

## 2. 核心方法

- 交替生成 Thought（自由文本推理）与 Action（结构化工具调用，如 `Search[...]`）；
- 运行时执行 Action → 得到 Observation → 拼回上下文 → 继续；
- 与 few-shot 示范结合：手工写 6~8 条 ReAct 轨迹作 prompt 示例。

## 3. 关键实验与结果

- HotpotQA：ReAct 比 CoT 绝对提升 10%+；ALFWorld 家居任务：绝对提升 34%；FEVER 事实核查：防幻觉能力显著提升。
- 失败分析：Thought 有时会"臆想"不存在的观察——引出后续 self-reflection 类工作。

## 4. 局限性与争议

- Thought 是自由文本，会泄露隐私信息到工具调用；单步错误会累积。
- 本质是 prompt 工程，能力上限受上下文长度制约。

## 5. 与本知识库的关联

模块 02 第 1 节；模块 05 agent loop 的理论原型（感知→思考→行动→观察）。
