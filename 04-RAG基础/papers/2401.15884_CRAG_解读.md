# 《CRAG: Corrective Retrieval Augmented Generation》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Shi-Qi Yan 等，北京大学 |
| 发表 | arXiv:2401.15884（KDD 2024） |
| 一句话总结 | 给 RAG 装一个"检索质量评估器"：检索结果分三档（正确/模糊/错误），错误时触发大动作纠偏（网页搜索兜底），模糊时做知识精炼——显著提升低质量知识库下的鲁棒性 |

## 1. 研究背景与问题

- 现实知识库质量参差：分块错误、OCR 错字、过期内容。Naive RAG 照单全收。
- 问题：**检索错了能不能先发现、再纠正？**

## 2. 核心方法

1. **检索评估器**：轻量模型对 (query, 检索文档) 打分，分三档：Correct / Ambiguous / Incorrect。
2. **纠错动作**：
   - Correct → 正常生成；
   - Ambiguous → **知识精炼**：把检索文档拆成细粒度知识条，去重重排后再用；
   - Incorrect → 触发外部 fallback（网络搜索/备用检索器）。
3. 与任何 RAG 即插即用（评估器独立训练）。

## 3. 关键实验与结果

- 在知识库被故意污染/缩短的设定下，相对 vanilla RAG 提升 10%+；干净库上也不掉点。

## 4. 局限性与争议

- 评估器本身的错误会成为新瓶颈；fallback 依赖外部搜索质量。
