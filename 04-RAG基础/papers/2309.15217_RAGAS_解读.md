# 《RAGAS: Automated Evaluation of Retrieval Augmented Generation》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Shahul Es 等，exploding gradients |
| 发表 | arXiv:2309.15217（EACL 2024 demo） |
| 一句话总结 | 不依赖人工标注的 RAG 评估框架：faithfulness / answer relevancy / context precision / context recall 四个指标全部用 LLM 自动打分 |

## 1. 研究背景与问题

- RAG 系统调参（分块大小、top-k、rerank）需要大量评估，人工标注太贵。
- 问题：**能否用 LLM 自动评估检索与生成质量？**

## 2. 核心指标（四件套）

1. **Faithfulness**：答案中的每个陈述是否能从检索上下文推出（防幻觉的核心指标）——分解陈述 → 逐条判定 entailment → 加权平均。
2. **Answer Relevancy**：答案与问题的相关度（反向生成问题再算相似度）。
3. **Context Precision**：检索结果里相关块排得够不够靠前。
4. **Context Recall**：检索结果是否覆盖了标准答案的要点。

## 3. 关键实验与结果

- 四个指标与人工判断的相关性显著高于 BLEU/ROUGE 等传统指标；已成为事实标准（ragas 库）。

## 4. 局限性与争议

- LLM-as-Judge 的偏差（偏好长答案、自信表述）会传导；生产环境应配合人工抽检。

模块 04 第 6 节评估框架；"先建 20 条测试集跑 RAGAS 再调参"的实践指南出处。
