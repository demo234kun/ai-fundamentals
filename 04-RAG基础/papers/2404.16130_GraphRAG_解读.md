# 《From Local to Global: A Graph RAG Approach to Query-Focused Summarization》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Darren Edge 等，Microsoft Research |
| 发表 | arXiv:2404.16130（2024.4） |
| 一句话总结 | GraphRAG：实体-关系图谱 + 社区检测 + 社区摘要 Map-Reduce，让 RAG 能回答"整个语料库的主题是什么"这类全局聚合问题——传统 RAG 的死穴 |

## 1. 研究背景与问题

- 向量 RAG 擅长"点对点"事实检索；面对全局性问题（"这套文档里主要的担忧是什么"）只能捡回碎片、无法概括全局。
- 问题：**如何让 RAG 支持全局理解？**

## 2. 核心方法（流水线）

1. **索引期**：LLM 从每个 chunk 抽取实体与关系（带描述和引用），构成知识图谱。
2. **社区检测**：Leiden 算法把图切成层次化社区。
3. **社区摘要**：自底向上对每个社区生成摘要（构成"摘要树"）。
4. **查询期（Map-Reduce）**：全局问题 → 取相关层的社区摘要逐块回答 → reduce 成最终答案，全程带引用。

## 3. 关键实验与结果

- 与朴素 RAG 对比：全局问题的全面性与多样性大幅领先；私有语料的 sensemaking 效果显著。

## 4. 局限性与争议

- 索引期要调用 LLM 抽图谱，**成本是向量索引的数倍到数十倍**。
- 实体抽取质量决定上限；结构化/半结构化语料收益最大。
