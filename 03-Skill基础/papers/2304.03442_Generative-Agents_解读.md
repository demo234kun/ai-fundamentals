## 1. 研究背景与问题

- 人类行为的可信模拟需要长期记忆、动态反思、自主计划。
- 问题：**纯 LLM agent 能否产生涌现式社会行为？**

## 2. 核心架构

1. **记忆流**：所有观察/思考/行动按时间记录。
2. **检索**：recency + relevance + importance 三因子加权取回。
3. **反思**：记忆积累到阈值后，LLM 把原始记忆综合成高层洞见（"倒影树"）——**低层事件蒸馏成高层知识**。
4. **规划**：自上而下展开"日计划→小时计划→行动"，与环境互动后动态调整。

## 3. 关键实验与结果

- 两天模拟中 agent 自发组织情人节派对；记忆三因子消融缺一不可。

## 4. 局限性与争议

- 纯 prompt 架构成本惊人；行为可信度评估主观。
