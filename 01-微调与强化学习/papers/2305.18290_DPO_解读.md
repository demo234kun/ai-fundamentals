# 《Direct Preference Optimization》（DPO）解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Rafael Rafailov 等，Stanford |
| 发表 | arXiv:2305.18290（NeurIPS 2023） |
| 一句话总结 | KL 约束 RLHF 的最优解有闭式形式，代入后 RL 问题坍缩成一个有监督二分类损失——不需要奖励模型和 PPO |

## 1. 研究背景与问题

- RLHF 痛点：四模型（Actor/Critic/RM/Ref）显存爆炸、PPO 超参敏感、流水线脆弱。
- 问题：**能否只用偏好对数据 + 一个损失函数直接对齐？**

## 2. 核心方法（推导是本篇精华）

1. 从 KL 约束的奖励最大化出发，最优策略有解析形式：`π*(y|x) ∝ π_ref(y|x)·exp(r(x,y)/β)`。
2. 反解出奖励：`r(x,y) = β·log(π*/π_ref) + β·log Z(x)`——**奖励可以用策略本身表达**。
3. 代入 Bradley-Terry 偏好模型，配分函数 Z(x) 在成对比较中消掉，得到：

   `L_DPO = −E log σ( β·log[π_θ(y_w)/π_ref(y_w)] − β·log[π_θ(y_l)/π_ref(y_l)] )`

- 直觉：拉开"好/坏回答"相对参考模型的对数概率差，sigmoid 变二分类。
- β 控制"离参考模型多远"：β 大 → 保守；β 小 → 更自由但易过拟合。

## 3. 关键实验与结果

- 在情感控制、摘要、单轮对话上匹配或超过 PPO-based RLHF。
- 实现极简：trl 的 DPOTrainer 几百行。

## 4. 局限性与争议

- 对分布外 prompt 可能过度自信（IPO 提出去 sigmoid 缓解）。
- 长度偏差：偏好"更长"的回答（SimPO/ORPO 针对此改良）。

## 5. 与本知识库的关联

模块 01 第 4 节的公式来源；KTO/SimPO/ORPO 的母体；偏好对齐的默认基线。
