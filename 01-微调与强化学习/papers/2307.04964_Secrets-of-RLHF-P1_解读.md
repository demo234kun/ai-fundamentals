# 《Secrets of RLHF in Large Language Models Part I: PPO》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | Jian Hu 等，DeepSeek-AI |
| 发表 | arXiv:2307.04964（2023.7） |
| 一句话总结 | DeepSeek 公开其 RLHF 系统的全部工程细节——奖励归一化、损失函数配对、PPO 实现 trick，是复现 RLHF 的"操作手册" |

## 1. 研究背景与问题

- 开源社区只会跑 SFT，RLHF/PPO 细节散落在各家闭源实现里，复现困难。
- 问题：**把 PPO 训练 LLM 的所有关键 trick 一次性讲清楚。**

## 2. 核心内容（按重要度）

1. **奖励归一化**：RM 输出做 running mean/std 归一化，防止奖励尺度漂移导致 PPO 崩溃——最易踩的坑。
2. **损失函数配对（loss pairing）**：对同一 batch 内的 prompt，分别算 SFT loss 和 PPO loss，二者配比调节避免"只 reward hacking 丢了语言能力"。
3. **过滤极端奖励**：clip 到 ±5 倍 std。
4. **价值函数初始化**：从 RM 初始化 Critic、 warming-up。
5. 训练曲线与超参全公开（7B/67B 两套）。

## 3. 关键结论

- 奖励分布会随训练漂移，不归一化 → PPO 后期崩溃。
- RLHF 对 SFT checkpoint 的选择很敏感。

## 4. 局限性与争议

- 只覆盖 PPO（奖励模型见 Part II）；时代背景是 2023 年的 LLaMA-1/2 规模。
