# 《BrowserGym: A Gym Environment for Web Task Automation》解读

| 项目 | 内容 |
|---|---|
| 作者/机构 | ServiceNow Research（Thibault Le Sellier de Chezelles 等） |
| 发表 | arXiv:2412.05467（2024.12） |
| 一句话总结 | 把"网页环境"标准化成 gym 接口（reset/step/reward），让不同 harness/模型能在同一基准上公平比较——研究 agent 环境的"基础设施论文" |

## 1. 研究背景与问题

- 网页 agent 论文各自造环境：动作空间不一（有的用 accessibility tree、有的用截图）、任务集不一，结果不可比。
- 问题：**能否像强化学习用 gym 一样，把网页任务环境标准化？**

## 2. 核心方法

1. **统一抽象**：`MiniWoB++ / WorkArena / WebArena` 等基准全部包成同一 `gym.Env` 接口：observation（DOM a11y tree + 截图 + 当前 URL）、action（点击/输入/滚动等原子动作 + 宏动作）、reward（任务成功判定）。
2. **AgentLab**：配套 harness，内置多种 agent 架构（ReAct、检索增强等），支持注册自定义 agent 一键评测。
3. **评测协议**：统一步数限制、统一轨迹记录格式。

## 3. 关键实验与结果

- 大规模横向对比 7 个 agent × 多个基准，揭示：动作空间设计对成功率的影响大于 prompt 技巧——再次印证 ACI（见 SWE-agent 解读）的结论。

## 4. 局限性与争议

- 只覆盖网页环境；动态网站/验证码等真实 web 难题仍缺。

## 5. 与本知识库的关联

模块 05"环境与 harness 解耦"范式的代表作；设计任何垂直 agent 评测时都可借鉴"统一环境接口"的思路。

## 6. 阅读建议

- 读 §2（环境抽象）与 §4（跨 agent 对比实验结论表）。如做 web agent，直接用它当基线框架。
